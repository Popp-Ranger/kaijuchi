# Kaijuchi

Un petit kaiju à élever, façon Tamagotchi. En ligne : https://popp-ranger.github.io/kaijuchi/

- **Sources** : `src/` (une feuille de style, la page, puis les scripts numérotés dans l'ordre de chargement).
- **Assembler** : `./build.sh` recolle tout dans `index.html`. Ne jamais modifier `index.html` à la main.
- **Tester** : ouvrir `index.html` dans un navigateur. La sauvegarde ne fonctionne que depuis un vrai navigateur ou le site en ligne.
- **Publier** : commit puis `git push origin main` ; GitHub Pages republie en une minute.
- **Plan de développement** : `PLAN.md`.
- `maquette.html` et `propositions.html` sont des références figées.
